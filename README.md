# Workspaces

Рабочие каталоги создаются в корне этого репозитория.
Скрипты находятся в `.scripts/`.

```sh
make new
make new NAME=learning-c
make all NAME=learning-c
make renumber
make test
```

`new` создаёт следующий каталог: `01`, `02-learning-c` и так далее.
`all` сначала перенумеровывает существующие каталоги, затем создаёт новый.
`renumber` показывает план и запрашивает подтверждение.
`make` без аргументов выводит справку.

Название передаётся через `NAME`. Без `NAME` создаётся каталог только с номером.
Пробелы в названии не допускаются.
Нумерация — строго от `01` до `99`. После `99` создание завершается ошибкой.
Перенумерация поддерживает каталоги с названием и без него, сохраняя содержимое.

Напрямую скрипты запускаются так:

```sh
./.scripts/new.sh learning-c
./.scripts/renumber.sh
```

Нужны Bash 3.2+ и Make. Для тестов нужен Python 3.
Тесты работают во временных каталогах.
